تقرير شامل عن محتوى المشروع وبنية الصفحات والعلاقات بينها
هذا المشروع منصة طبية مبنية على Django تمكّن المرضى من رفع حالاتهم الطبية والحصول على ردود من أطباء معتمدين، مع دعم لغتين (العربية والإنجليزية) واتجاه RTL.

أعرض أدناه كل الصفحات الرئيسية حسب التطبيقات (apps) في المشروع، مع دور كل صفحة والعلاقات بينها ومسارات الوصول.

1) اللبّ (Core)
المسارات: core/urls.py
/ → الصفحة الرئيسية HomeView
القوالب:
templates/core/home_enhanced.html (للعربية افتراضيًا)
templates/core/home_en.html (للإنجليزية)
تعرض: أرقام إجمالية (عدد الأطباء المعتمدين، الحالات، المرضى) + أطباء مميزين.
/about/ → AboutView
القالب: templates/core/about.html
/contact/ → ContactView
القالب: templates/core/contact.html
نموذج تواصل بسيط مع رسائل نجاح.
/faq/ → FAQView
القالب: templates/core/faq.html
/set-language/ → set_language
تبديل اللغة وتخزينها في الكوكيز/الـ session، مع دعم نقطة API ترجمة فورية داخل نفس الـ view عند POST خاص.
علاقات مهمة:

معظم عمليات تسجيل الدخول/الخروج تعيد التوجيه إلى صفحات core أو لوحات التحكم حسب نوع المستخدم.
الصفحة الرئيسية تعرض بيانات من doctors, patients, accounts.

9) ملاحظات خاصة باللغات والواجهة
النظام يدعم العربية والإنجليزية مع RTL للعربية.
اختيار القالب الرئيسي للصفحة الرئيسية يتبدل حسب اللغة.
يوجد محولات ترجمة فورية لواجهة المستخدم وAPI.
تم ضبط صفحة enhanced_doctor_register لتطابق تصميم doctor_register مع الحفاظ على التحقق الفوري للأسعار.
إذا رغبت، يمكنني توليد خريطة روابط HTML (sitemap) أو مخطط تدفق رسومي (Mermaid) يوضّح العلاقات بين الصفحات خطوة بخطوة لكل دور. كما أستطيع إضافة روابط تنقل واضحة بين الصفحات في الواجهات لتسهيل الانتقال ضمن التدفقات.

الطريقة المختصرة الموصى بها أول مرة
نفّذ مرة واحدة فقط:
تثبيت الحزم:
pip install -r requirements.txt
تطبيق الترقيات (احتياطيًا):
python manage.py migrate
تشغيل السيرفر:
python manage.py runserver

يثبّت الحزم + يطبّق الترقيات + ينشئ superuser + يضيف بيانات تجريبية
للتشغيل اليومي: انقر run.bat
يفتح المتصفح ويشغّل السيرفر
ما هو اختياري وليس مطلوبًا للتشغيل
إنشاء superuser: فقط إذا تريد دخول Django Admin في /admin/
إعداد Stripe/PayPal وملف .env: فقط إذا تريد اختبارات دفع حقيقية
أوامر compilemessages/الترجمة: فقط إذا عدّلت النصوص وتريد تحديث ملفات الترجمة
